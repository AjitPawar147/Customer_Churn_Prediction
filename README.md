# Customer Churn Prediction

This project is a Machine Learning application that predicts customer churn using customer behavior and service usage data. The model helps businesses identify customers who are likely to leave their services, allowing companies to improve customer retention strategies.

---

## Project Overview

Customer churn prediction is an important business problem in industries like telecommunications, banking, and subscription-based services. This project uses Machine Learning algorithms to analyze customer data and predict whether a customer will churn or stay.

The dataset used in this project is the Telco Customer Churn dataset.

---

## Features

- Customer data analysis
- Data preprocessing and cleaning
- Exploratory Data Analysis (EDA)
- Handling categorical and numerical features
- Feature encoding using OneHotEncoder
- Feature scaling using StandardScaler
- Machine Learning model training
- Customer churn prediction
- Model evaluation using accuracy score
- Model saving using Joblib
